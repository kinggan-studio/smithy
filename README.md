# 炉火铁匠铺

一个原创的单人网页小游戏：经营一家小铁匠铺。每天去市场买进武器，锻造升级，卖出或交给客人的订单赚钱，买工具改变概率，付房租撑下去，直到成为传奇铁匠。

- 玩法类型：赌运气的锻造 + 经营。规则、工具、数值、文案均为本项目原创设计。
- 单页 HTML，无后台、无账号、不收集数据；进度只存在你自己的浏览器里（localStorage）。
- 在线玩：https://kinggan-studio.github.io/smithy/
- 本地玩：用任意静态服务器打开（如 `npx serve .`）。直接双击 `index.html` 也能玩，但真实音效需要通过网页服务器加载。

## 素材说明
- `art/`：画面素材由 AI 图像工具生成，再经人工整理和切图，不含其他游戏的素材。
- `audio/`：音效是程序合成的原创声音，详见 `audio/SOURCES.md`。
- 如果你对任何素材的来源有疑问，请在 Issues 里告诉我。
